# Carson Kahila Portfolio

This repository contains the HTML skeleton for my personal portfolio site. It was created for the Semantic HTML Portfolio Skeleton lab.

## Project Goals

The site is built with semantic HTML only and does not use CSS. It includes:

- Primary navigation with anchor links
- Intro section
- About section
- Experience section
- Projects showcase
- Skills section
- Contact section
- An image with descriptive alternative text
- An external LinkedIn link
- Meaningful metadata
- ARIA labels and labeled landmarks
- Semantic elements such as `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `dl`, `time`, `address`, and `footer`

## Files

- `index.html` - Main portfolio page
- `content.md` - Content plan used before building the HTML
- `images/wayne.jpg` - Image used in the intro section

## Validation

Before submitting the lab, validate `index.html` with the W3C Markup Validation Service:

https://validator.w3.org/

Fix any reported HTML errors before the final deployment.

## Deployment

The completed site should be deployed through Netlify from the GitHub repository.
